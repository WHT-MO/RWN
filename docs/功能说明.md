# RWNoctiluna 功能说明

面向玩家与服主的功能使用说明。安装方法见随包《安装说明.txt》。

## 对局统计

自动记录**打完的多人对局**（中途退出、单机遭遇战、沙盒、观看回放、**观战均不记录**）。

- **查看**：主菜单 → `10 对局统计`
  - 顶部汇总：总局数 / 胜率 / 累计时长
  - 列表：每局的胜负、地图、人数、日期、时长（最多保留 200 条，超出自动裁掉最旧的）
- **删除记录**：记录保存在游戏目录的 `match_history.toml` 文件中
  - 删除该文件 = 清空全部记录（下次对局结束自动重建）
  - 用文本编辑器打开该文件，删掉若干条目的段落 = 部分删除
- **胜负判定**：以"本机玩家所在队伍是否获胜"为准；全员投降打完的局同样记录

## 房间预设（房主）

**预设 = 房间设置 + 移动规则**（不只是位置预设）——保存时把面板当前的
全部房间设置（共享控制/初始资金/初始单位/雾模式/AI 难度/收入倍率/禁核/
允许观战/游戏速度）和移动规则一起存成模板，建房后一键恢复。

- **位置**：多人房间 → 房间设置 → "应用"按钮左侧（仅房主可见）
- **保存为预设**：把面板当前的 9 项配置和移动规则存为命名模板（自动记
  保存时间，下拉列表显示）
- **移动规则**："移动序号x玩家到序号x位置、x队伍"
  - 序号 = 玩家**当前所在出生点位**（1-10），与队伍无关，空位不影响编号
  - 位置 = 出生点位（留空则只换队伍）
  - 目标位被占时自动与占用者交换位置，队伍按各自规则独立处理
- **编辑预设**：下拉选中 → "编辑预设" → 对话框预填该预设的全部规则与
  名称 → 改完保存（同名覆盖，改名另存）
- **使用**：下拉选择预设 → 自动填入面板（可继续微调）→ 点"应用"生效；
  队伍分配随"应用"按房主移动玩家指令逐个下发
- **删除预设**：下拉选中后点"删除预设"
- 预设保存在游戏目录 `room_presets.toml`，可备份/分享；仅本机面板数据，
  实际生效永远走房主的"应用"，非房主不可见

## 观战排行榜

给观战玩家（或部队全灭的败局玩家）的**全场信息面板**——与回放界面同款：

- **入口**：对局中游戏内的"排行榜"按钮（仅本机无单位时可见；拥有单位
  即自动隐藏——面板含全体经济/部队价值，参战玩家持有即信息透视）
- 点击面板循环切换排序：无 / 收入 / 部队价值 / 建筑价值 / 总价值 / 现金
- 观战者全图视野与原版一致（反作弊巡逻自动跳过观战玩家，不误伤视野）

## 工厂生产队列显示

己方工厂（陆/空/海厂+基地，含模组工厂）头顶显示**待生产队列**，
如"坦克×7"——最多两类竖排两行，引擎精确居中。

- **开关**：设置 → 游戏性 → "工厂头顶显示生产队列（仅己方）"，默认关闭
- **仅己方**：盟友/敌方工厂不显示（看不到工厂内部）
- **远视角自动隐藏**：缩小镜头到全局视野（缩放因子<0.30）时文字
  自动消失，不遮挡视野；拉回操作视角即恢复
- 类型显示中文名（与游戏内一致）；队列空时不显示

## 视野范围显示

- **己方侦察单位**（侦查者 / 无人侦察机）：设置 → 游戏性 → 开启"显示侦察单位视野"后自动显示视野圈
- **任意单位**（含敌方）：选中单位后点击游戏内额外按钮 `显示视野范围` / `显示攻击范围` 单独切换
- 视野圈半径与游戏引擎的迷雾揭示范围一致（含模组单位的自定义视野）

## 迷雾巡逻（反作弊）

对局中自动防御修改内存的透视类作弊（浓雾 LOS Fog 下同样有效），全部在本机运行：

- 翻转迷雾开关类作弊 → 立即自动恢复
- 修改迷雾数据型透视 → 周期性自动重扫压回（开局 30 秒高频防御）
- 可见格突变（全图透视特征）→ 立即触发额外重扫
- 设置 → 游戏性 → `迷雾巡逻` 可调档位（关闭 / 标准 / 严格），单机默认关闭，联机自动启用"严格"
- 无感知运行，不弹窗、不影响正常对局；观战玩家自动豁免

## 单位方案快捷键（类型编组）

把常用单位组合（如"坦克+修理"）绑到自定义按键，对局中一键选中场上
**所有匹配类型的本机存活单位**（含工厂新产出——按键时实时查询）。

- **配置**：设置 → 单位方案快捷键 → 开启开关（默认关）→ 新建方案
- **键位**：点击键位框后**按一个键即录入**（字母/数字/F1-F12）；与其他
  方案或引擎快捷键重复时仅黄色提示，不阻止
- **与原生编组的关系**：完全不干扰 Ctrl+数字编队——本功能只改"当前
  选择"，不碰编队数据
- 边界：匹配 0 个单位时无操作；聊天框或引擎菜单打开时按键不触发；
  共享控制时按引擎规则可选中友方单位（与原生一致）

## 界面

- **主菜单**：左侧竖排菜单（01-10）；右上角依次为 公告 / GitHub / 关于 / 退出
- **背景透明度**：设置中调节，主菜单面板浓度联动
- **回到原版**：任何时候从 Steam 启动游戏即完全原版；删除游戏目录 `generated_lib/` 文件夹即彻底还原

## 常用文件位置

| 文件（游戏目录下） | 用途 |
|---|---|
| `match_history.toml` | 对局统计记录（删除即清空） |
| `room_presets.toml` | 房间预设模板（可备份/分享） |
| `generated_lib/` | 注入产物（删除即还原原版） |
| `Settings.toml` 等 | 各设置项（含迷雾巡逻档位、单位方案） |
