# RWNoctiluna 功能说明

面向玩家与服主的功能使用说明。安装方法见随包《安装说明.txt》。

## 对局统计

自动记录**打完的多人对局**（中途退出、单机遭遇战、沙盒、观看回放均不记录）。

- **查看**：主菜单 → `10 对局统计`
  - 顶部汇总：总局数 / 胜率 / 累计时长
  - 列表：每局的胜负、地图、人数、日期、时长（最多保留 200 条，超出自动裁掉最旧的）
- **删除记录**：记录保存在游戏目录的 `match_history.toml` 文件中
  - 删除该文件 = 清空全部记录（下次对局结束自动重建）
  - 用文本编辑器打开该文件，删掉若干条目的段落 = 部分删除
- **胜负判定**：以"本机玩家所在队伍是否获胜"为准；全员投降打完的局同样记录

## 房间预设（房主）

把常用的房间配置和队伍分配存成模板，建房后一键恢复。

- **位置**：多人房间 → 房间设置 → "应用"按钮左侧（仅房主可见）
- **保存为预设**：把面板当前的 9 项配置（共享控制/初始资金/初始单位/雾模式/
  AI 难度/收入倍率/禁核/允许观战/游戏速度）**和当前全部玩家的队伍分配**存为命名模板
- **使用**：下拉选择预设 → 自动填入面板（可继续微调）→ 点"应用"生效；
  队伍分配随"应用"按房主移动玩家指令逐个下发
- **删除预设**：下拉选中后点"删除预设"
- 预设保存在游戏目录 `room_presets.toml`，可备份/分享；仅本机面板数据，
  实际生效永远走房主的"应用"，非房主不可见

## 视野范围显示

- **己方侦察单位**（侦查者 / 无人侦察机）：设置 → 游戏性 → 开启"显示侦察单位视野"后自动显示视野圈
- **任意单位**（含敌方）：选中单位后点击游戏内额外按钮 `显示视野范围` / `显示攻击范围` 单独切换
- 视野圈半径与游戏引擎的迷雾揭示范围一致（含模组单位的自定义视野）

## 迷雾巡逻（反作弊）

对局中自动防御修改内存的透视类作弊（浓雾 LOS Fog 下同样有效），全部在本机运行：

- 翻转迷雾开关类作弊 → 立即自动恢复
- 修改迷雾数据型透视 → 周期性自动重扫压回
- 设置 → 游戏性 → `迷雾巡逻` 可调档位（关闭 / 标准 / 严格），单机默认关闭，联机自动启用"严格"
- 无感知运行，不弹窗、不影响正常对局

## 界面

- **主菜单**：左侧竖排菜单（01-10）；右上角依次为 公告 / GitHub / 关于 / 退出
- **背景透明度**：设置中调节，主菜单面板浓度联动
- **回到原版**：任何时候从 Steam 启动游戏即完全原版；删除游戏目录 `generated_lib/` 文件夹即彻底还原

## 常用文件位置

| 文件（游戏目录下） | 用途 |
|---|---|
| `match_history.toml` | 对局统计记录（删除即清空） |
| `generated_lib/` | 注入产物（删除即还原原版） |
| `Settings.toml` 等 | 各设置项（含迷雾巡逻档位） |
